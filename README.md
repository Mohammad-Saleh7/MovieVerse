# 🎬 MovieVerse

**MovieVerse** is a modern movie and TV show discovery platform built with **Next.js**, **React**, and the **TMDB API**.

Discover trending and top-rated titles, search for movies and TV shows, explore detailed information, watch trailers, and keep track of your favorites and watchlist.

## ✨ Features

- 🎬 Movies & TV Shows
- 🔥 Trending & Top Rated
- 🔍 Search
- 🎥 Trailers
- 🎭 Cast & detailed information
- ❤️ Favorites
- 🔖 Watchlist
- 🕘 Watch History
- 🌐 English & Persian
- ↔️ RTL support
- 🌙 Dark & Light mode
- 📱 Responsive design
- ⚡ Loading & error states
- 🔎 Localized metadata & SEO

## 🛠️ Built With

- **Next.js**
- **React**
- **Tailwind CSS**
- **next-intl**
- **shadcn/ui**
- **TMDB API**

## 🚀 Getting Started

```bash
git clone <repository-url>
cd movieverse
npm install
```

Create a `.env.local` file:

```env
TMDB_API_KEY=your_tmdb_api_key
```

Start the development server:

```bash
npm run dev
```

Then open:

```text
http://localhost:3000
```
